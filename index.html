Filter

Coherence Filter sends your extracted text to Anthropic's Claude API to rewrite it as prose — the only thing in TextScanner that leaves your device. Your API key is stored only in this browser.

One caveat worth knowing: on the web version, that storage belongs to the whole github.io origin, not just to TextScanner — any other site published at the same origin can read the key back. Use a key scoped and budget-limited to this, and remove it with “Change key” when you're done.

Text is positioned where it appeared in the source image. Click a word to edit it, or shift-click and drag to select multiple.
