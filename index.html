      Rewriting with —

      On-device rewriting uses Apple's built-in language model. Nothing leaves your device, no API key is needed, and it costs nothing.

      Coherence Filter sends your extracted text to Anthropic's Claude API to rewrite it as prose — the only thing in TextScanner that leaves your device. Your API key is stored only in this browser.

      One caveat worth knowing: on the web version, that storage belongs to the whole github.io origin, not just to TextScanner — any other site published at the same origin can read the key back. Use a key scoped and budget-limited to this, and remove it with “Change key” when you're done.

      This engine doesn't report per-word confidence, so no words are flagged for double-checking. Read the result with that in mind.

        Storage

        Checking...

        Documents, pages and thumbnails are stored on this device only. Nothing is uploaded, there is no account, and there is no sync.

        Translation history

        History records the text you translated so you can find it again without re-running it. It is capped and trimmed automatically. Saved phrases are never trimmed.

        Diagnostics

        Builds a report (timestamp, recognition engine, device/browser info, and the last scan error if there was one) and hands it to your device's share sheet or a download — nothing is sent anywhere on its own; you choose the destination.

        Delete everything

        Permanently removes every document, page, image and translation on this device. This cannot be undone, and there is no copy anywhere else.

        About

        Recognition runs on your device, using Tesseract.js. Your images are never uploaded anywhere.
