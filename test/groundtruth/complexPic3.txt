DESIGN & IMPLEMENTATION SPECIFICATIONS
1. Global Header (All Pages)
Left: Logo (existing)
Right (order): Courses | Profile | Hamburger Menu | Logout
Hamburger contains: Exams, Question Banks, Exports, Help & Onboarding, Contact Support
2. Home (Courses Dashboard)
Left sidebar (25-30% width)
Title "Courses" left, "Create Course" right
Search bar with placeholder "Search Courses"
Toggle: Active (primary) / Archived (secondary)
Course cards: ID (large), course name, offering
Selected course shows purple outline + background
Right content area (70-75% width)
If no course selected: empty state with icon + message
If course selected: show Section 1 (Course Details) and Section 2 (Workspace)
3. Section 1 – Course Details (Top Right Panel)
Header: "Course Details" with info icon (hover: "Select a course to view details")
Right buttons: Student Roster | Student Reports | Analytics
Collaborators row (existing UI):
Add Collaborator input on same line
Added users shown below in one or more lines
If overflow: show "read more..." → expand to show all with "show less"
4. Section 2 – Workspace (Bottom Right Panel)
Default = Exams list (existing implementation)
Shows exam cards with REAL statuses:
Draft (gray)
Finalized (blue)
Completed (green)
Analytics Available (purple)
Each card shows: title, date, question count, variants, avg score, status badge, and "Open Exam" button
"View all exams" link at bottom (existing behavior)
5. Workspace Tabs Behavior
Student Roster: show existing roster UI (add/import/export visible in this panel)
Student Reports: embed existing "Student Reports & Export" page as-is (this panel only)
Analytics: show exams list and placeholder message exactly as shown
Switching tabs retains left sidebar selection and top collaborator section
6. Navigation Behavior
Clicking an Exam card opens the existing Exam Details page in a new route
Browser back returns to the same course dashboard with the same tab
All existing permissions/RBAC must continue to apply
7. Authentication Improvements
Add "Remember me" on login (persist session/refresh token as implemented)
Add show/hide password toggle (eye icon)
8. Onboarding
Show on first login after account creation
Step-based tour highlighting:
Courses list
Top header (navigation)
Course details section
Workspace tabs
Where to manage exams, students, reports
Skip / Next / Back / Done
Replay from Help & Onboarding (hamburger menu)
Store completion in user profile
